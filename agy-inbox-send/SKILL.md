# agy-inbox-send（Gemini ➔ Antigravity 引き継ぎ出力スキル）

Gemini 上で行った音声壁打ち（Gemini Live）、通常チャット、深い調査・長文生成、または Canvas でのプロトタイプ制作の内容を、**劣化なく Antigravity の開発・タスク化フローへ引き渡す**ための送り出しスキルです。

## 設計思想

- 会話や試作の状態にある間はまだ「タスク」ではありません。Antigravity 側へ引き継いでタスク化・統合するまでのあいだ、Google Drive の `Antigravity-Inbox` に「1 話題 ＝ 1 パッケージ（壁打ち Doc 1 枚 ＋ 成果物があれば同梱）」としてまとめます。

## 実行手順

このスキルが呼び出されたら、以下の手順で出力を作成してください。

### 1. スレッド全体の棚卸し
ここまでの会話履歴・Canvas の成果物・長文ドキュメントをすべて確認し、抜け漏れがないように整理します。

### 2. 話題タイトルの決定
1 話題を識別しやすい短いタイトルを決めます（推奨形式：`YYYY-MM-DD_<短い話題名>`）。

### 3. 引き継ぎ用「壁打ちドキュメント」の生成
以下のテンプレートに沿って、過不足なく構造化された Markdown（そのまま Google ドキュメントへエクスポートできる形式）を出力します。長文コンテキストがある場合は、雑談を省きつつ、重要な決定・数値・仕様・制約は省略せずに残してください。

```markdown
# <話題タイトル>

- **作成日**: YYYY-MM-DD
- **引き継ぎ元**: Gemini（Live / チャット / Canvas / 長文生成）
- **想定される作業種別**: 新規開発 / 既存リポジトリ改修 / 調査・設計 / その他

## 1. 目的・ゴール
（何を実現したいか、なぜやるのか）

## 2. 背景・前提・制約
（会話の中で確定した前提条件、ターゲット環境、使いたい／使いたくない技術やルール）

## 3. 決定事項
- （合意・確定したこと）

## 4. 未決事項・Antigravity 側で詰めたい論点
- （まだ決まっていないこと、実装前に確認すべき判断ポイント）

## 5. 詳細コンテキスト・仕様メモ
（長大な調査結果や要件定義がある場合は、要点を落とさずここに構造化して記載する）

## 6. 同梱成果物一覧（Canvas プロトタイプ等がある場合）
- `<ファイル名>`：役割・どこまで動いているか・配置時の注意点
（成果物がない場合は「なし」）

## 7. 最初の一歩（タスク候補）
- [ ] （Antigravity が受け取った直後に着手すべき具体的タスク）
```

### 4. Google Drive `Antigravity-Inbox` への格納案内
出力の最後に、ユーザーへ次の格納手順を簡潔に案内してください（Google Workspace 連携ツールが有効な場合は、ユーザー確認のうえで直接作成・保存しても構いません）。

- **壁打ちテキスト・長文のみの場合**:
  1. 上記ドキュメントを Google ドキュメントにエクスポート（または保存）する。
  2. Google Drive の **`Antigravity-Inbox`** フォルダへ配置する。
- **Canvas のプロトタイプなど成果物ファイルがある場合（話題別フォルダ・バンドル方式）**:
  1. **`Antigravity-Inbox`** フォルダの中に **`<話題タイトル>`** というサブフォルダを作成する。
  2. そのフォルダの中に **上記の壁打ち Google ドキュメント 1 枚** と **Canvas 等の成果物ファイル一式** をまとめて入れる。
- **次のステップ**:
  - PC またはリモートエージェント上の Antigravity で **`agy-inbox-receive`**（「Inbox を確認して」「Gemini から引き継いで」等）を呼び出すと、取り込み・タスク化・自動アーカイブが実行されます。
